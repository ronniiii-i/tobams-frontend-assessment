## 📦 Getting Started

1. Clone the repository:

   ```bash
   git clone <your-github-repo-url>
   cd tobams-frontend-assessment
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Run the development server:

   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📐 Design Decisions & Assumptions

- Applied standard responsive breakpoints via Tailwind (`sm:`, `md:`, `lg:`) targeting 425px, 768px, and 1280px+.
- Organized modular, reusable UI components within `src/components/`.
- Utilized `next/font` for optimal typography loading and `next/image` for image optimization.
